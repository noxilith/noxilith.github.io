EloraNotes

A calm, minimalistic desktop notes app written in Rust with eframe / egui. Every note is a plain Markdown file on your disk, and the app stays out of the way while you write.

LINUX/MACOS/WINDOWS/GPL-3.0

01 Overview

EloraNotes is a cross-platform notes application built in Rust. It keeps a small, quiet interface: a narrow sidebar of notes on the left, one note in the editor, and a footer row for the daily note, the command palette and settings.

Notes are stored as portable .md files with lightweight YAML frontmatter, so you can read, back up or edit them in any other editor. Nothing is locked in a database.

Where your notes live

By default notes and the settings file (.elora-settings.json) live in Documents/EloraNotes, which is C:\Users\<you>\Documents\EloraNotes on Windows. Every install format uses that same folder, including the Flatpak, so the same notes open whichever build you launch. Notes from the older default folders are copied there on first launch, leaving the originals untouched.

To use a different folder, pass --dir or set ELORA_NOTES_DIR:

elora --dir ~/Notes

02 Features

  • Write in Markdown, see it rendered. Switch between raw editing, side-by-side split view and a clean preview. The formatting bar inserts headings, bold, italics, lists, tasks, quotes, code blocks and wiki links in one click.
  • Formatting that stacks. Markers nest, so **==bold inside a glow==** or {color:#4ECDFF}**colored bold**{/color} render as a single run carrying several styles. Headings can carry highlights and text colours too.
  • Wiki links and backlinks. Write [[Note Title]] or [[Note Title|Alias]] to reference another note, click through to it in preview or split, and see everything that points back in the Linked from footer. Show Links That Lead Nowhere lists every wiki link whose target does not exist yet.
  • A sidebar that fits more. Each note is one line — a small icon and its title — so about twice as many fit at once. Notes can be filed into collapsible folders that show their contents stepped in and remember whether they were folded.
  • Pictures, by button, drop or paste. Insert an image from the formatting bar, drop a file on the window, or paste a screenshot with Ctrl+V; it is copied into an attachments folder beside your notes. In preview you can drag the corner of a picture to resize it, and the size is saved in the note.
  • Task checklists you can click. Tick - [ ] boxes directly in preview or split view, with progress badges such as 2/3 on the note card and in the editor header.
  • Pipe tables. A row of cells followed by | --- | :---: | ---: | is drawn as a table in preview and split, columns aligned the way the colons ask, and it exports as a real <table>.
  • Daily notes and templates. Open or create today's dated note in one keystroke, or start from the Meeting Notes and Project Spec templates in the command palette.
  • Export and import. Export the current note or the whole vault as standalone HTML pages, with pictures copied alongside and wiki links rewritten to point at the exported pages. Importing a folder of Markdown files copies them in as notes, frontmatter kept.
  • Shared notes, Google-Docs style. Point the app at an EloraNotes server and its notes appear in the sidebar, with live edits, coloured carets and a presence list. The full server setup guide lives in the repository README.
  • Five themes. Obsidian, Paper, Nordic, Matcha, or Matugen to pull colours from your wallpaper. Window size, position and preferences persist between launches.
  • Updates itself. On launch it checks GitHub for a newer release, verifies the download runs, then installs it the way this copy was installed.

04 Install

Every release ships an installer and a portable build for each platform. Grab them from the latest release.

PlatformInstallerPortable
Linux.flatpak.AppImage or .tar.gz
Windows-setup.exe-portable.exe
macOS (Apple Silicon).dmg.zip with EloraNotes.app

Linux

The Flatpak is the installable build — it appears in your app menu and updates itself from this repository's releases.

flatpak install --user ./EloraNotes-<version>-linux-x86_64.flatpak
flatpak run io.github.noxilith.EloraNotes

The bundle is self-hosted rather than published to Flathub, so flatpak update has no remote to pull from and will always say there is nothing to do. Updates arrive through the app's own Update and restart. To move to a newer bundle by hand, download it and run the same flatpak install --user command again.

The AppImage is the portable build: a single file you can keep anywhere.

chmod +x EloraNotes-<version>-linux-x86_64.AppImage
./EloraNotes-<version>-linux-x86_64.AppImage

The tarball holds the bare elora binary if you would rather put it on your PATH:

tar -xzf EloraNotes-0.7.0-linux-x86_64.tar.gz
sudo install -Dm755 elora /usr/local/bin/elora

Windows

Run the -setup.exe and follow the wizard. It installs for the current user only (no administrator prompt), adds Start Menu and optional desktop shortcuts, and registers EloraNotes under Settings → Apps → Installed apps so it can be uninstalled from there. The -portable.exe needs no install at all: put it in a folder and run it.

macOS

Open the .dmg and drag EloraNotes into Applications. The .zip is the portable build — unzip it and run EloraNotes.app from anywhere.

The builds are not notarised, so the first launch needs right-click → Open (or System Settings → Privacy & Security → Open Anyway) once.

Uninstalling

  • Linux (Flatpak): flatpak uninstall io.github.noxilith.EloraNotes. Your notes stay in ~/Documents/EloraNotes; the updatable copy of the app lives in ~/.local/share/EloraNotes and can be deleted once the bundle is gone.
  • Linux (AppImage or tarball): delete the file.
  • Windows: Settings → Apps → Installed apps → EloraNotes → Uninstall.
  • macOS: drag EloraNotes.app from Applications to the Trash.

Your notes are plain .md files and stay where they are either way.

05 Updates

On launch the app compares its version with the latest GitHub release and, when one is newer, offers Update now or Later. What an update does depends on how the copy was installed:

  • AppImage: the new image is downloaded beside the old one, started once to prove it runs, then swapped in and relaunched.
  • Windows setup: the new installer runs silently over the old install, keeping shortcuts and the uninstall entry correct, then the app restarts.
  • macOS app bundle: the new EloraNotes.app replaces the old one, which is cleaned up on the next launch.
  • Portable exe or tarball binary: only the executable is replaced, so it has to live in a writable folder.
  • Flatpak: the bundle's launcher runs a writable copy from ~/.local/share/EloraNotes, so the update replaces that binary and restarts like the portable build. The sandbox itself stays as installed.

Settings → Updates shows the version you are running, checks on demand and installs the result, so you never have to wait for the next launch.

06 Run from source

You need a Rust toolchain. On Linux, NixOS and macOS the repository includes a launcher that sets up the environment:

./run.sh

Otherwise build and run with Cargo:

cargo run --release

The collaboration server builds on its own, without the GUI libraries a headless machine would not have:

cargo build --release --no-default-features --bin elora-server
ELORA_SERVER_DIR=~/.config/elora-server ./target/release/elora-server init
./target/release/elora-server run

Notes and settings are found in Documents/EloraNotes unless you point the app elsewhere with --dir or ELORA_NOTES_DIR.
